# DATING-MATCHMAKING

A full-stack dating and matchmaking web application designed to connect users through preference-based algorithms and real-time interaction.

## Features

- **User Authentication:** Secure sign-up, login, and profile management.
- **Matchmaking Algorithm:** Automated profile matching based on user preferences and compatibility criteria.
- **Real-Time Communication:** Direct chat functionality between matched users.
